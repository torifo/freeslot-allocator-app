FRELOCATOR

Privacy Policy

Last updated: 2026-04-26

FRELOCATOR is a personal planning app for managing daily schedules, tasks, and weekly reviews.

Information we handle

At the current stage, FRELOCATOR stores user-created planning data such as tasks, schedules, and related settings on the user’s device.

  • Task data
  • Daily plan data
  • Basic local app settings

How data is stored

Current app data is stored locally on the device using platform-provided local storage. The current implementation does not require account registration and does not provide cloud sync.

Information sharing

FRELOCATOR does not sell user data. Based on the current implementation, app data is not intentionally transmitted to a separate backend service operated by us for core usage.

Third-party services

Distribution platforms, hosting providers, or analytics tools may handle limited technical data according to their own policies. This page describes the app’s current behavior and should be updated if additional services are introduced later.

Data control

Because the current app stores data locally, deleting the app or clearing app data on the device may remove stored planning information.

Changes

This policy may be updated when app features, storage methods, or platform requirements change.
