# 機能チェックリスト

モバイル向けデバッグと受け入れ確認のためのチェックリストです。まずは `must` 相当の項目から確認します。

## TaskMaster

- [ ] タスクを追加できる
- [ ] タスクを編集できる
- [ ] タスクを削除できる
- [ ] `やるべきこと / やりたいこと` を切り替えられる
- [ ] 見積もり時間が保存される
- [ ] 存在しないカテゴリを持つタスクが未分類へ落ちる

## カテゴリ設定

- [ ] 初期カテゴリが表示される
- [ ] カテゴリを追加できる
- [ ] カテゴリを編集できる
- [ ] カテゴリを削除できる
- [ ] 同名カテゴリを作ろうとするとエラーになる
- [ ] 共有カテゴリ ON で統合ルールを選べる
- [ ] 共有カテゴリ OFF で両区分に一覧が残る

## DailyPlan / FreeTimeSlot

- [ ] 日付ごとに `DailyPlan` を作成できる
- [ ] slot を追加できる
- [ ] slot を編集できる
- [ ] slot を削除できる
- [ ] 日またぎ slot を作成できる
- [ ] 同一日の重複 slot を保存できない

## SlotTaskAssignment

- [ ] 予定を追加できる
- [ ] 予定を編集できる
- [ ] 予定を削除できる
- [ ] 枠外の時間は保存できない
- [ ] 同一 slot 内の重複予定は保存できない
- [ ] slot 間へドラッグ移動できる
- [ ] slot 内の任意位置へ再配置できる
- [ ] ドラッグ中に drop 先が視認できる

## 複製機能

- [ ] 別日複製ができる
- [ ] slot 単位で部分複製できる
- [ ] assignment 単位で複製対象を選べる
- [ ] 予定を含める / 含めないを切り替えられる
- [ ] 追加 / 置換を選べる
- [ ] 重複する slot を複製しようとするとエラーになる

## 週次レポート

- [ ] 前週 / 今週 / 次週を切り替えられる
- [ ] 割り当て時間が正しく集計される
- [ ] 週またぎ予定が重なった分だけ集計される
- [ ] `やるべきこと / やりたいこと` の内訳が出る
- [ ] その週に割り当てた予定の見積もり合計が出る
- [ ] カテゴリ名変更後も最新名で集計される

## モバイルUI

- [ ] 小さい画面でも主要ボタンが押せる
- [ ] ダイアログ内フォームが見切れない
- [ ] 縦スクロールで主要操作へ到達できる
- [ ] 長押しドラッグ時に誤操作しにくい
- [ ] SnackBar やエラー文言が読める
