# UX ウォークスルー所見 (v4 / 2026-09-09)

v4 (1.0.0+4) の実機ウォークスルーで洗い出した UX 課題。v5 (1.0.0+5) で対応する。

## CRITICAL

| ID | 箇所 | 内容 |
| --- | --- | --- |
| C-1 | `qr_receive_screen.dart` / `sync_settings_screen.dart` | 案内文に `sync_status` / `lan.qrPage` など内部ツール名が露出。ユーザー語に置き換える。ツール名は macOS の `McpGuideSection` 内のみに留める。 |
| C-2 | `sync_settings_screen.dart` `_editHost()` | 保存時のフィードバックなし・入力検証なし・既定値が `10.0.2.2`。保存 SnackBar、ホスト/ポート検証、未ペアリング時の案内カード、プレースホルダ `192.168.x.x`・ポート既定 47820 に変更。 |

## IMPORTANT

| ID | 箇所 | 内容 |
| --- | --- | --- |
| I-1 | 日次計画 空き枠モーダル | 開始を終了より後にすると負の分数が表示される。終了を「開始＋従前の長さ（0 なら +60 分）」へ追随。不正時はインラインエラー＋保存無効。 |
| I-2 | 割り当てダイアログ | タスク選択時に終了時刻が見積もり (`estimatedMinutes`) を反映しない。終了＝開始＋見積もり（0 なら 30 分）。 |
| I-3 | `task_master_screen.dart` | カテゴリ設定へ `context.go` で遷移し戻れない。`context.push` へ。 |
| I-4 | カテゴリ削除 | 使用中タスク件数を伝えない。「このカテゴリを使っている N 件のタスクは未分類になります。」を確認ダイアログに追加。 |
| I-5 | `_CategorySection` | `Flexible` でタイトルが不要に省略される。ボタン側の `Flexible` を外す。 |
| I-6 | カテゴリ名 / 優先度フィールド | エラー・ヘルパー文が 1 行に収まらず切れる。`errorMaxLines: 2` / `helperMaxLines: 2`。 |
| I-7 | タスクダイアログ | 優先度・見積もりに数字以外が入力できる。`digitsOnly` + 範囲検証（優先度 1..5 / 見積もり 0..1440）。優先度は `SegmentedButton` 化。 |
| I-8 | 同期設定 | 「エミュレーター」という開発者用語が UI に出る。文言から削除（C-2 に統合）。 |
| I-9 | QR 受信 | カメラ権限拒否・利用不可でも進捗ティッカーが回り続け「時間がかかっています」と出る。失敗状態へ遷移し、代替手段の案内をプラットフォーム別に出す。 |
| I-10 | 「別日に複製」 | 取り込み方向が伝わらない。「別日から取り込む」へ改称、ダイアログ題は「取り込み元の日付を選択」。計画のない日は選択不可に。 |
| I-11 | 日次計画リスト | FAB が最終行に被る。`padding: bottom 96`。 |
| I-12 | `router.dart` / `HomeBottomNav` | ボトムナビがホームにしか無く、現在地も常に「今日」固定。`StatefulShellRoute.indexedStack` で 5 ブランチの永続ナビへ。`/sync*` はシェル外の push ルート。 |
| I-13 | 全体 | UI に `TaskMaster` / `DailyPlan` の内部名が出る。「タスク」「日次計画」へ統一。動詞は「当日計画を作成」に一本化、「やめる」→「キャンセル」。 |
| I-14 | 枠バッジ | 枠 0 件と未設定が区別できない。`hasConfiguredSlots ? '枠 N 件' : '枠 未設定'`。 |
| I-15 | タスク一覧 | 副題が更新日時で情報価値が低い。メモ 1 行目（省略付き）に置き換え、日時は表示しない。 |

## MINOR（対応）

- M-3 タスク画面の空状態はセクション別ではなく全体で 1 つに。0 件時はドラッグ案内も出さない。
- M-4 フィルタチップを 3 等分または自然幅 `Wrap` に。
- M-6 空き枠の既定値を「現在時刻の次の 30 分区切り → +60 分」に。
- M-7 「モーダル」「Google カレンダーのように」を文言から削除。
- M-8 「…ファイルでデータをやり取りします」→「ファイル経由でやり取りします」（「デ／ー」での改行回避）。
- M-10 スマートフォン（最短辺 < 600）は縦固定。タブレットは `_WideHome` を維持。
- M-11 `colorScheme.error` をテラコッタ (`0xFFB4472E`) に。
- M-12 ホーム / 計画カードに「残り X 時間 Y 分」（空き時間 − 割り当て済み）を表示。
- M-16 メモ欄 `alignLabelWithHint`、ダイアログをスクロール可能にしてキーボードで題が隠れないように、タイムラインの枠ブロックをグリッド内に収めて淡い塗り、ドラッグ中のみドロップ先ラベルを表示、書き出しファイル名はローカル時刻、ドロップダウンの配色をテーマから、カテゴリ/タスクの保存・削除に成功 SnackBar。
